# NYC TLC Trip data

In this project, we created details analysis of trip demand and revenue using **Tableau desktop**

The dataset was sourced from this link: (https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)

**Outcome of the project**

* **North Harlem** south had the most number of trip in a single day.
* Overall, the **demand was higher in the evening**.
* The **zone with most demand is not associated with maximum average revenue**
